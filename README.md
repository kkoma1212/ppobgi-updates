# 뽑기 시간 — 업데이트·공지

교실용 번호 뽑기 프로그램 「뽑기 시간」의 **업데이트와 공지만** 올리는 저장소입니다. 프로그램 소스 코드는 여기 없습니다.

- `index.html` — 관리자 웹(공지 작성, 업데이트 배포). GitHub Pages로 열립니다.
- `notices.json` — 앱에 보이는 공지(글자만).
- `release.json` — 배포된 판 정보. 제작자 PC의 비밀 키로 **서명**되어 있어, 앱은 서명이 맞을 때만 받습니다.
- 릴리스(Releases) — 화면 묶음(`bundle-*.ppobgi`)과 필요할 때 전체 실행 파일.
